SCHOOL BRAWL CUP — ОБНОВЛЕНИЕ ТУРНИРНОЙ СИСТЕМЫ

В архиве находятся файлы с готовыми путями. Их нужно загрузить в корень репозитория GitHub, сохраняя структуру папок.

ФАЙЛЫ:
- tournament.html — публичная страница турнира и архива.
- css/tournament.css — стили сетки и управления.
- js/tournament.js — публичное отображение турниров.
- js/tournament-admin.js — управление турниром в админке.
- js/admin.js — текущая админка с передачей токена модулю турнира.
- admin.html — добавлена секция управления турниром.
- netlify/functions/tournament.mjs — публичный API турнира.
- netlify/functions/tournament-admin.mjs — защищённый API управления.

ВАЖНО:
1. Таблицы tournaments, tournament_teams и tournament_matches уже созданы в Supabase. SQL повторно запускать не нужно.
2. Не удаляйте существующие файлы регистрации и команды.
3. После загрузки GitHub автоматически запустит Netlify deploy.
4. После deploy сначала войдите в admin.html, проверьте, что секция турнира появилась.
5. Создание турнира использует только одобренные и опубликованные команды.
6. Завершение турнира сохраняет архивную сетку и составы, а исходные команды только скрывает из публичного списка — строки в teams не удаляются.

СПИСОК КАРТ:
Используется пул Ranked Season 51 (ноябрь 2026), 24 карты в шести режимах. Сезонные карты могут измениться при следующем обновлении игры; список в коде потребуется обновить при смене сезона.
