SCHOOL BRAWL CUP 2.0 — обновление

В архиве находятся файлы обновления. Структура папок уже правильная.

КАК УСТАНОВИТЬ
1. Распакуй архив.
2. Открой GitHub: https://github.com/xeysla177/school-brawl-cup
3. Нажми Add file → Upload files.
4. Перетащи содержимое распакованной папки в окно загрузки, сохраняя папки и пути.
5. Нажми Commit changes.

ВАЖНО

- Не загружай сам ZIP вместо распакованных файлов.
- Обновление не удаляет заявки и не создаёт турнир автоматически.
- Поле tournaments.details уже добавлено в подключённую базу Supabase.
- Файл database/tournament-migration.sql оставлен в репозитории как документация миграции; повторно выполнять его необязательно.
- После загрузки дождись статуса Published/Ready в Netlify. Только затем проверяй сайт.
